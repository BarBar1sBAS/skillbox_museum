# Design

## Sources
Приоритет: «На грани доверия» (HEX при расхождении с RGB), пользовательские скриншоты, аудит v2. Исходные тексты игры являются основными.

## Theme
Светлая тема по умолчанию, сохранённый ручной переключатель. Днём на телефоне посетитель читает условия на спокойной светлой поверхности; вечером доступна тёмная тема.

## Palette
Light: #E9E9EF фон, #0B4AF9 действие, #00001A текст. Dark: #15141A фон, #2A2A2A поверхность, #02CEFB действие. Белый и чёрный из брендбука разрешены. Зелёный #22EE88 только награды и шифр; тёмный текст успеха #126B43.

## Typography
Локальные Halvar Breitschrift Regular для заголовков, Bold для цифр. Halvar Mittelschrift для условий. Основной текст 16px/1.55. Системный monospace только для терминального сообщения. Нет искусственного Light.

## Layout
Максимум 1200px, поля 20–48px. От 900px две смысловые колонки, ниже одна. Прямоугольные элементы. Ступенчатые маски только у иллюстраций.

## Motion
CSS transform/opacity; ease-out cubic-bezier(0.23,1,0.32,1). Управление 150–250ms, одно появление глича 480ms, сообщение 840ms, награда 420ms. Reduced motion убирает глич и перебор. Нет бесконечных циклов.

## Components
Storybook содержит компоненты обеих тем, ошибки изображений, длинные ответы, шифр 0–3, награды. Изменения поведения начинаются с падающих тестов Vitest.
