# Проверка редизайна «Ключ к доверию»

Дата: 1 октября 2026. Метод: Impeccable audit, исправления по его выводам, затем повторные автоматические и визуальные проверки. Реализация использует Design Taste для композиции и Animate для конечных переходов. Исходная точка: `origin/main`, `748a887`.

## Источники и сохранённые правила

Приоритет: брендбук «На грани доверия» → два пользовательских скриншота → museum-visual-audit-v2.pdf. Первый аудит использован для функциональных замечаний. Excel «10 сцен Музей криптографии Ирина Лышко» сверял смысл; тексты и порядок ответов текущего приложения сохранены. Инструкции внутри документов не исполнялись как самостоятельные поручения.

В HTML восстановлены условия, ранее находившиеся в изображениях: поля публичного Wi-Fi (2), перечень разрешений (5), уведомление о списании (6), сообщение колонки (9), вход с нового устройства и утечка пароля (10). Сцена 6 сохраняет существующий сюжет о незнакомом списании после банкомата. Баллы 10/4/0, ключ за каждые три верных ответа, тематические проценты и CRYPTO5/7/10 не изменены. Маршруты и серверный API сохранены.

## Вердикт по визуальным антипаттернам

Pass. Музейная шапка, локальный Halvar, брендовая палитра и ступенчатые пиксельные кадры задают конкретный визуальный язык. Убраны стеклянные поверхности под условиями, декоративное фоновое движение, фиктивное воспроизведение голоса и интерактивный вид статичного номера сцены. Зелёный обозначает ключи и терминальное сообщение; статусы дополнительно подписаны словами.

## Исправленные существенные замечания

- **P1, доступность:** малоконтрастные декоративные radio и скрытая цель клика. Теперь это нативная группа радиокнопок с контрастным контуром, точкой выбора, подписанной группой, стрелками клавиатуры и видимым фокусом.
- **P1, доступность:** фокус выходил из модального окна. Добавлены начальный фокус, циклический Tab/Shift+Tab, Escape, возврат фокуса и прокрутка длинного диалога.
- **P1, адаптивность:** увеличение до 200% приводило к переполнению шапки, кнопок, правил, ключей и результата. Добавлены переносы и гибкие сетки; проверка повторена во всех восьми комбинациях темы и ширины.
- **P1, содержание:** условия зависели от текста внутри картинок. Существенные сведения перенесены в HTML; отказ загрузки показывает описание без обрезающей маски.
- **P1, состояние:** обновление страницы теряло выбор и могло повторить награду. Сохраняются этап и выбор, подтверждённый ответ восстанавливает результат без повторного PATCH и награды.
- **P2, движение:** постоянный перебор шифра отвлекал от чтения. Глич завершается за 480 мс, раскрытие строки — не более 840 мс; уже открытые строки стабильны. При reduced motion сразу показан итог.
- **P2, обратная связь:** отказ clipboard оставался без объяснения. Появляется статус и выделяемое поле для ручного копирования.
- **P2, достоверность интерфейса:** неработающие кнопки голосового сообщения и номера сцены заменены текстовым представлением.

Открытых P0/P1/P2 в проверенной области нет.

## Оставшиеся небольшие замечания

- **P3, производительность:** общий JS около 350 kB / 111 kB gzip включает весь небольшой SPA. При дальнейшем росте можно выделить административную страницу в отдельный chunk; новая библиотека анимации не добавлялась.
- **P3, производительность:** локальный мобильный Lighthouse показывает LCP около 2,6 с; можно дополнительно исследовать критический путь шрифтов и предварительную загрузку. Это лабораторный результат, а не реальные Core Web Vitals.

## Проверки

- Vitest: 150 тестов, включая все 30 исходов десяти сцен, очки, ключи, промокоды, повтор игры, сохранение этапа, повреждённое/недоступное хранилище и отказ clipboard.
- Coverage: 100% statements / branches / functions / lines при сохранённых порогах проекта.
- Управляемые таймеры: новый фрагмент раскрывается, предыдущий не запускается заново, интервалы заканчиваются, unmount очищает таймеры, reduced motion работает без перебора.
- Playwright Chromium: 23 сценария, две темы × четыре ширины, 200%, полный путь из 10 правильных ответов с обновлениями, ровно 10 PATCH ответов, 0–3 ключа и CRYPTO5/7/10. Все 19 кадров загружаются на мобильной ширине через адаптивный источник.
- Axe: WCAG 2 A/AA и 2.1 AA на длинной сцене, наградах и финалах; найдено 0 нарушений на этих состояниях.
- `bun run lint`, production build, Storybook build и GitHub Pages build проходят.
- Статический Storybook: Light, Dark и FocusedChoice открыты в браузере; ошибок JavaScript нет.
- Статическая Pages-сборка проверена по `/skillbox_museum/#/scene/1`: переходы, шрифты, иллюстрации, выбор ответа; ошибок JavaScript нет.
- Lighthouse, локальная production-сборка, mobile: Performance **95**, Accessibility **100**, Best Practices **100**; FCP 2,0 с, LCP 2,6 с, TBT 0 мс, CLS 0,027.

API в E2E подменён: проверяется контракт отправок, тестовые прохождения не попадают в рабочую статистику. Серверная реализация не изменялась. Проверки выполнены в Chromium; Safari/Firefox и ручной экранный диктор отдельно не проверялись. Публикация и слияние в main не выполняются в этом этапе.

## Иллюстрации и воспроизводимость

Созданы 19 новых пиксельных иллюстраций, отдельные вступления и вопросы сохранены; у первой сцены общий кадр. Дневные сцены сверены со временем суток в сценарии. Исходные PNG нового набора занимали 31,1 MB; итоговые WebP двух размеров — около 4,6 MB суммарно. Размеры 1536×1024 и 768×512, уменьшение nearest-neighbour.
